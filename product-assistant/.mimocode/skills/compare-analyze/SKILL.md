# 对比与竞品分析（compare-analyze）

## 流程（克制检索）

1. 确认对比对象（2～3 个为宜）。  
2. **每个对象 1 次** `rag_search`（对象名 + 关键维度，`top_k=5`）；对象超过 3 个时优先用户点名的。  
3. 直接输出表格 + 3 条内结论 + 信息缺口。  
4. 无出处单元格写「库内未找到」，不编数字。  

## 输出

```
| 维度 | A | B |
|------|---|---|
结论：…
缺口：…
依据：`path` § …
```

## 禁止

- 用训练常识填竞品参数  
- 每个维度单独搜一轮（会拖到几十秒）
