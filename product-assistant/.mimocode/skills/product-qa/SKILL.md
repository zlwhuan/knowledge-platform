# 产品知识问答（product-qa）

基于 MCP `product-rag` 作答。**优先快答**，减少工具轮次与输出长度。

## 快速路径（默认，务必遵守）

1. **直接 `rag_search`**（`top_k=5`）：用用户问题里的产品名/型号/关键词一次检索。  
   - 问题已清晰时：**不要**先调 `rag_ingest_status`，**不要**多轮改写检索。  
   - 首轮命中不足（空结果或明显跑题）时，再补 **最多 1 次** 检索。
2. **立即作答**，格式从简：

```
结论：（1～3 句）
依据：`path` § 章节 — 要点
```

3. 命中里已有完整参数/步骤时，**不要**再调 `rag_get_document`。

## 何时加严

- 用户问「对比 / 全文 / 招标细节」→ 可对每个对象各搜 1 次，或读 1 次原文。  
- 疑似知识库为空 / 怀疑没入库 → 才调 `rag_ingest_status`。  
- 库内无依据 → 写「文档库中未找到」，禁止编造。

## 禁止

- 无出处编造参数、价格、工期  
- 为「显得专业」堆长背景、空话  
- 无必要的 2+ 轮检索与全文朗读  

## 示例

- `rag_search(query="X1 最大并发连接", top_k=5)`
- `rag_search(query="重症 建设目标", top_k=5)`
