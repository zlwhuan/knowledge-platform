# 销售 / 客服话术（sales-assist）

基于 MCP `product-rag`，**快答**。

## 流程

1. **1 次** `rag_search`（产品名 + 客户问题关键词，`top_k=5`）。  
2. 立刻给话术：

```
一句话主张：…
正式版：（3～6 句）
依据：`path` § 章节
红线：库内无依据则不承诺工期/价格/未写明功能
```

3. 仅当要对比竞品时，对竞品材料再搜 1 次；未知项写「以最新商务资料为准」。

## 禁止

- 无依据承诺功能/工期/价格  
- 长篇营销空话  
- 多轮无目的检索
